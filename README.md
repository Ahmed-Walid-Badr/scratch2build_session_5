# Scratch2Build - Session 5
## JavaScript DOM Mutation & Event-Driven Engine

Welcome to Session 5 of the FCAI E-Club Scratch2Build Web Development Track!

This session focuses on making static web pages interactive using JavaScript, DOM manipulation, and event-driven programming.

## 🎯 Learning Objectives

By completing this session, you will understand how to:

- Understand the DOM Tree and how browsers represent HTML elements.
- Select and manipulate DOM elements using JavaScript.
- Handle user interactions using `addEventListener()`.
- Understand Event Bubbling and Event Delegation.
- Prevent default browser behavior using `e.preventDefault()`.
- Understand the difference between Reflow and Repaint.
- Use Array Methods such as `filter()`, `map()`, and `join()`.
- Dynamically update the UI based on application data.
- Debug JavaScript errors using Chrome DevTools.

## 📚 Topics Covered

1. DOM Selection and Memory Representation.
2. DOM Manipulation and Dynamic Element Creation.
3. Event Listeners and Event Delegation.
4. Event Bubbling and Event Targets.
5. Reflow vs Repaint.
6. Declarative UI and Array Methods.
7. Form Validation.
8. Real-Time Search and Filtering.
9. JavaScript Debugging.
