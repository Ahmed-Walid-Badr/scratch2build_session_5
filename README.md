# Scratch2Build – Week 3: JavaScript DOM & Events

## Overview
In this session, we will learn how to make static web pages interactive using JavaScript. We will explore how JavaScript interacts with HTML elements and responds to user actions.

## What We Will Learn
- Modern JavaScript (ES6+): `let`, `const`, arrow functions, and template literals.
- DOM Manipulation: selecting, creating, modifying, and removing HTML elements.
- Event Handling: using `addEventListener()` to respond to clicks, inputs, and form submissions.
- Event Bubbling and `preventDefault()`.
- Closures and how they affect dynamic UI behavior.
- Array methods: `map()`, `filter()`, and `forEach()`.

## Mini Task: Fix the Counter
You will work on a small JavaScript counter application that contains a bug related to closures.

### Your Tasks
1. Open the provided `index.html` file in your browser.
2. Examine the JavaScript code in `buggy.js`.
3. Identify why the counter does not behave as expected.
4. Fix the stale closure issue.
5. Make sure the counter works correctly after your changes.

## Before the Session
- Review basic JavaScript syntax and functions.
- Make sure you understand HTML elements and how JavaScript selects them.
- Bring your laptop and be ready to participate in the coding challenge.

## Important
The goal is to understand how JavaScript can dynamically update web pages and respond to user interactions.
